# jovel.app

Statische SPA/PWA für den MÜNSTERHACK.

## Lokal starten
`npx serve .`

Die JSON-Dateien liegen unter `data/` und werden vom Service Worker offline gecacht.
Die Teamnamen in `data/rooms.json` sind absichtlich fiktive Beispiele.
